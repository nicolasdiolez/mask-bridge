# أوتو ماسك برو - فئات الاكتشاف (Mask Bridge - Detection Classes)

يكتشف محرك RF-DETR **80 فئة من الكائنات** من مجموعة بيانات COCO. إليك القائمة الكاملة التي يمكنك استخدامها في الإعدادات المتقدمة (Advanced Settings).

⚠️ **هام:** يستخدم محرك الذكاء الاصطناعي هذه المصطلحات باللغة الإنجليزية. لذلك، يجب عليك إدخال المصطلحات الأصلية (باللغة الإنجليزية) في الإضافة.

## ⚠️ القيود

**لا يمكن اكتشافها بواسطة RF-DETR:**
- الكابلات / الأسلاك
- المباني / المنازل
- الأشجار (باستثناء "potted plant")
- السماء / الغيوم
- الطرق / الأرصفة
- الجبال / المناظر الطبيعية

---

## 💡 الاستخدام في أوتو ماسك برو (Mask Bridge)

في قسم **الإعدادات المتقدمة (Advanced Settings)**، اكتب الفئات باللغة الإنجليزية مفصولة بفواصل:

```
person, car, dog
```

### 🧠 الفئات الذكية (الماكرو)
يمكنك استخدام هذه المصطلحات العامة لتحديد فئات متعددة في وقت واحد:

| الكلمة المفتاحية | يكتشف |
|------------------|-------|
| **vehicle** | car, motorcycle, bus, train, truck |
| **animal** | bird, cat, dog, horse, sheep, cow, elephant, bear, zebra, giraffe |
| **furniture** | chair, couch, bed, dining table, bench, toilet |
| **electronics** | tv, laptop, mouse, remote, keyboard, phone |
| **sports** | جميع المعدات الرياضية + skateboard, surfboard, tennis racket |
| **plant** | potted plant (النباتات) |
